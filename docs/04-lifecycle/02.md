# 4.2 信息去重与融合

[全书首页](../../README.md) · [本章导读](README.md)

> 概念说明与参考设计，非已实现系统报告。资料核验日期：2026-11-13。

## 要解决的问题

去重、融合与巩固有何不同？

去重识别重复，融合协调互补，巩固形成紧凑组织。每次变换保留输入和转换记录，避免压缩后的结论失去出处。

### 4.2.1 精确去重

两份采集结果完全相同，先判断它们是不是同一来源版本的重复观测。如果只是网络重试，应复用来源身份并保留采集记录；如果属于不同租户或有效期，则不能因文本相同直接合并业务对象。

内容哈希用于比较字节或规范化文本，规范化规则也要明确。例如空白可以统一，数字和否定词不能随意清除。发现哈希相同后仍要检查作用域和来源关系，避免去重破坏权限与审计。

Mem0 所读路径对召回的旧记忆和本批候选做文本哈希去重。因此未进入旧召回集的重复内容可能不在这次比较范围。若要求全局唯一，应增加按作用域维护的唯一键或专门去重索引，而不是把有限召回当作完整集合。[R14][固定版本源码](https://github.com/mem0ai/mem0/blob/f1791daa86d469249c9b002f62644d58a1eb96a0/mem0/memory/main.py#L918-L1098)。

### 4.2.2 语义去重

#### 四条相近文本为什么不能一次合并

设同一项目的候选为 A“普通发布至少两名不同审批者”、B“普通发布需要不少于两名不同审批者”、C“紧急发布由一名当值负责人审批”、D“普通发布恰好两人审批”。检索可能把四条都排得很近，因为项目、发布和人数词汇高度重合。

A 与 B 在核对来源、时间及“审批者”定义后可成为等价候选；C 因场景不同必须保留为分支；D 即使也写 2，仍与“至少”具有不同约束，且可能遗漏身份条件。把它们压成“发布需一到两人”不仅没有消除歧义，还生成了原材料都不支持的新要求。

确认 A、B 等价后，保留一个业务命题并关联两次来源观测；若 B 是 A 的镜像，不能把它当成第二份独立佐证。合并记录要能反向找到 A、B 和字段映射。后来发现 B 引错项目时，可以撤销该支持关系，而不必删除 A 的有效依据。

Mem0 的文本哈希去重会跳过部分完全相同文本，却不会据此判定 A 与 B 的语义等价；这正是精确去重与语义归一的责任边界。不能因为已有 hash 字段，就省略条件比较与误合并恢复。[R14][实际去重范围](https://github.com/mem0ai/mem0/blob/f1791daa86d469249c9b002f62644d58a1eb96a0/mem0/memory/main.py#L1007-L1045)

### 4.2.3 实体归一化

“Atlas”“Atlas 服务”和项目 ID atlas-prod 可能是同一对象，也可能指项目、服务与环境三个实体。归一前查实体类型、组织、上下文和已有别名，不能仅依赖名称相似。

确认后将不同提及关联到稳定 ID，保留原文称呼及合并依据。误合并时需要能够撤销关系并重建受影响记忆；没有独立身份与来源，纠错会变成逐条猜测哪些内容属于谁。

具体到两个 Atlas 候选：一个属于组织 o1 的项目 p1，另一个属于 o2 的服务 s9。名称接近只构成匹配线索；对象类型和归属不同，应先分开。只有权威注册表或明确来源说明某简称指向 p1，才新增别名关系。确认后仍保留原提及，避免误关联时无法找回受影响记录；把两个 ID 永久压成一个字符串会使撤销更困难。

### 4.2.4 知识合并

两份规范分别写人数与角色限制时，可以组织成完整规则，但必须确认它们适用于同一场景和版本。合并后的陈述应保留每个条件各自的证据，不能让一个引用看起来支持全部结论。

若一份针对普通发布，另一份针对紧急发布，应保留条件分支。知识合并的目标是减少冗余并增加可解释联系，不是消除所有差异；未决冲突需要独立保存。

融合的可逆性来自保留映射，而不是只保留合并后文本。设 A、B 合并为 C，至少记录 C derived_from A@v、B@v，以及哪些字段来自哪一输入。若发现 A 错误，可重建 C 而不用猜测哪些句子受影响。对于人工主题页，需要给维护者显示受影响段落。

实体误合并的修复比文本去重更昂贵，因为下游关系会迁移。可先生成 same_as 候选，经审核再合并 ID；对高风险实体保留两个对象并显式展示歧义。

### 4.2.5 记忆巩固（Memory Consolidation）

同一用户多次说“先给结论”，可以归纳为默认偏好；但若其中一次限定项目、一次只是赶时间，直接统计频次会错误扩大范围。巩固先按主体、属性和条件组织事件，再决定哪些内容支持稳定结论。

保留当前摘要与原始表达的关联。新更正到来时，重建受影响摘要；不能只在旧摘要后不断追加补丁。重复的模型自述也不是多份独立证据，不能用它强化未经确认的偏好。
