## 本章模型

以下为参考设计，箭头表示处理方向或职责联系，不代表已部署组件。

```mermaid
flowchart LR
 Data[冻结数据与划分] --> Config[锁定配置]

 Run --> Record[保存输出和证据]
 Record --> Score[独立评分与复核]
```
