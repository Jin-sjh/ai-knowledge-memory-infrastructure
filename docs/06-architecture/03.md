# 6.3 核心服务模块

[全书首页](../../README.md) · [本章导读](README.md)

> 概念说明与参考设计，非已实现系统报告。核验日期：2026-11-13。

## 要解决的问题

模块边界如何防止职责混乱？

每个模块拥有清楚的对象和写权限，其他模块通过契约请求变化。治理模块可施加全局可见性限制，但不应静默改写内容语义。

### 6.3.1 Source Management

来源模块管理输入身份、快照、权限与采集进度。同一来源重试不应生成无关文档，来源变化则产生新版本，并通知派生处理。

采集成功但后续提取失败时，保留已确认的来源与阶段错误，以便重试处理；不能把整条链的成败混成一个导入状态。

### 6.3.2 Knowledge Management

知识模块管理规则、概念和事实候选及其验证、发布关系。它应能回答某条结论依据哪份规范、何时有效、是否有未决冲突。

提取器可以提出候选，但批准与替代由明确策略控制。新增来源时不能直接把所有模型输出写成现行知识，否则下游检索会失去可信状态边界。

### 6.3.3 Memory Management

记忆模块管理主体历史、偏好、经历及当前投影。收到新表达时核对范围、长期意图与既有记录，保存事件或更新档案，并通知依赖失效。

它与聊天存档不同，也与任务游标不同。用户撤回偏好应停止相关用途，而不是只让新聊天覆盖旧聊天。

例如表达事件 e3 已写入，但当前档案仍为 e1。若接口承诺下一轮立即遵从更正，记忆服务必须在返回完成前更新当前投影，或让读取端能够识别并处理未追平状态；只保证事件追加成功不足以满足这项承诺。若产品允许异步生效，则明确返回处理中及查询方式。服务边界应以用户可观察行为定义，而不只以哪张表写成功定义。

### 6.3.4 State / Checkpoint Management

状态模块为运行保存精确位置、输入版本和待确认动作。例如页 4 写入超时后，恢复端需要知道远端结果未知，而不是简单从页 3 再执行全部步骤。

检查点与副作用账本协作：状态记录在哪里，账本记录做过什么，业务查询确认外部现状。三者缺一时都可能重复或遗漏动作。

### 6.3.5 Retrieval & Context Management

检索模块按范围产生候选，上下文模块决定哪些候选进入本次输入。两者的结果应分开记录，才能区分漏召回与预算淘汰。

当前规则、用户偏好和工具状态以不同用途进入装配；冲突未解决时限制结论，不能让生成模型自行从混合材料中猜哪个有效。

### 6.3.6 Lifecycle & Governance

#### 一个删除请求怎样分配模块责任

u1 删除答复偏好后，记忆模块定位目标身份并建立停用状态；治理模块查询依赖，派发向量删除、摘要重建和缓存清理；访问模块在各副本尚未清理时仍拒绝使用目标。来源模块再按原始输入的保留承诺处理原文，不能默认删偏好就允许永久保留所有对话。

| 模块 | 它确认什么 | 它不能代替谁确认 |
| --- | --- | --- |
| 记忆服务 | 目标对象停止当前用途 | 所有外部副本已清除 |
| 访问服务 | 本次没有返回被阻断内容 | 后台物理清理完成 |
| 索引与摘要处理 | 自己负责的副本已处理 | 其他存储也已完成 |
| 治理协调 | 已登记任务的整体进度 | 未登记副本必然不存在 |

若摘要生成者从未登记来源，治理模块就无法精确枚举，这属于数据契约缺陷，不是多加一次删除重试能解决。每个模块发布派生物时都要建立依赖，治理才可能给出可解释的完成状态。

LlamaIndex 的文档标识与引用删除是文档级管理的具体机制。系统增加 Wiki、Claim 或回答缓存后，必须补充这些外部派生物的依赖登记，不能把向量删除当作完整治理。治理完成条件应由所有已登记副本共同确认。[固定版本源码](https://github.com/run-llama/llama_index/blob/baeabbfe26241a6916e13e2a8c8156a02e0602cd/llama-index-core/llama_index/core/ingestion/pipeline.py#L469-L507)。

职责矩阵可按拥有者、读者和事件消费者定义：Source 独占来源版本写入；Knowledge 和 Memory 创建信息对象；Retrieval 只读有效对象并管理访问索引；Governance 发起限制和清理；Runtime 独占检查点。共用主库时可在服务协调下同事务完成跨模块一致变更。

明确“谁不得写”同样重要：检索器发现相似内容不能自行合并事实；上下文压缩器不能把摘要自动存成长期记忆；经验提取器不能改变运行游标。

模块所有权不排除共享事务，应在同库场景优先利用事务减少中间态。
