# 5.1 信息访问基础

[全书首页](../../README.md) · [本章导读](README.md)

> 概念说明与参考设计，非已实现系统报告。核验日期：2026-11-13。

## 要解决的问题

不同查询应该走哪条访问路径？

先识别查询意图与精确约束，再选择 SQL、全文、向量、图或直接阅读。检索技术是互补工具，所有路径都要经过相同可见性与时态约束。

### 5.1.1 精确查询与 SQL / API

问“u1 当前在 Atlas 的答复偏好是什么”，主体、范围和属性已明确，按键查询当前档案比语义搜索更直接。精确查询返回确定对象或不存在，不需要让新旧偏好在相似度上竞争。

同样，审批是否完成应查业务状态或受控 API。模型可解释返回结果，但不能用相关聊天代替当前执行事实。

官方 LangGraph 示例按 namespace/key 读取偏好，不需要 embedding；Store 的使用不等于向量搜索。实现联合访问时，可让精确档案和项目文档走不同路径，在候选已经完成授权后再合并。性能与正确率应分别测量。[固定版本源码](https://github.com/langchain-ai/langgraphjs/blob/959f041dfb8f6bbafa6af3ebb4bc20484a9290da/libs/checkpoint/src/store/memory.ts#L188-L219)。

### 5.1.2 关键词与全文检索

关键词检索适合精确名称、错误码、版本号和术语，例如搜索 ERR_ROLE_MISMATCH。它能保留字面匹配优势，却可能漏掉“审批者角色不符”这样的改写。

需要决定分词、字段和排序口径，保留命中位置供回查。不要因为文本包含错误码就认定故障原因相同，后续仍需比较环境与时间。

### 5.1.3 Embedding 与语义检索

语义检索帮助把“为什么部署被拦住”匹配到“审批条件未满足”，适合措辞不同的问题。生成查询向量后取相近文本，再将结果作为候选核对。

相关性不能替代状态和权限。旧规范可能更接近问题措辞，镜像文档也可能占据多条结果，因此先后还需版本过滤、重复控制与证据选择。

### 5.1.4 Hybrid Search

#### 融合分数怎样改变选择，怎样又不能改变资格

假设字面检索将当前规则 d1 排第一、旧版说明 d2 排第三；语义通道将 d2 排第二、d1 排第二十。按前述 c=60 的 RRF 计算，d2 的综合分反而更高。这不是算法矛盾：它综合的是两路排名，未承诺按现行版本选择。

若查询当前审批要求，d2 已过期就应退出候选资格，不能靠给 d1 多加一个权重来碰运气；若查询历史制度，d2 又可能正是需要的对象。由此可见，融合规则与时态筛选回答不同问题。

再看镜像：三个 URL 若都是 d2 的转载，不能先占据三个结果槽，再把它们当作独立支持。参考流程按来源身份或已确认内容映射去重，保留各通道排名与镜像观测；按任务资格过滤后，再在可用候选里排序。

排名融合适合不同通道分数无法直接比较的情况，但不是所有查询都必须融合。已知对象身份时先精确读取，关系路径问题可先查图，再将解释材料交给文本访问。选择依据是任务所缺信息，而非给每个问题都调用全部索引。

混合搜索让关键词和语义通道分别取候选，再按共同身份去重和融合。错误码主要依赖字面通道，概念改写可能由语义通道补足，两者解决不同漏召回。

不能直接相加不同量纲的原始分数。可使用预先定义的排名融合，并在开发集验证；合并后仍检查作用域和有效状态，不能让某通道绕过过滤。

RRF 的一个参考形式为 score(d)=Σ 1/(c+rank_r(d))，只对检索器返回的文档累加，缺席项不加分。示例 c=60，d1 排名为 1 和 20，得分约 0.02889；d2 排名 3 和 2，约 0.03200。因此 d2 更靠前。c 是需要开发集选择的参数，不是固定最佳值。

融合使用排名避免直接混加 BM25 和余弦分数，但不能补偿权限错误、索引漏召回或错误文本。融合前后都保留检索器排名，便于解释最终结果。

### 5.1.5 图关系与路径查询

图查询适合沿明确关系找对象，例如“这个组件升级影响哪些服务”。系统从组件出发沿依赖方向遍历，返回路径和关系来源，使影响判断可以解释。

图中没有边不一定表示没有影响，可能只是资料未覆盖；关系有边也不一定证明当前有效。应说明图的覆盖边界和时间，不把路径存在直接当成因果证明。

### 5.1.6 Long Context 与直接阅读

短而完整的现行规范可以直接读入上下文，省去切块召回造成的遗漏。材料增多后仍需筛选权限、版本与预算，不能把所有历史无差别拼接。

直接阅读也有选择问题：截断可能删掉例外，顺序可能影响使用。评测应保存实际输入，检查决定答案的条件是否真的在窗口中，而不是只看文件总长度。
