# 统一术语表

本表是工程操作性约定，不取代所有学科定义。

| 术语 | 本书含义 | 不能混同 |
| --- | --- | --- |
| Knowledge | 可复用的组织化陈述和关系 | 无条件真理 |
| Memory | 主体为未来管理的历史信息 | 全部日志或向量 |
| Experience | 环境、行动与结果的关联 | 普遍规则 |
| State | 执行控制与业务状态 | 自然语言回忆 |
| Context | 本次调用实际输入 | 全部持久化信息 |
| Source | 输入对象及版本 | 天然权威来源 |
| Evidence | 支持或反驳命题的片段 | 任意相关链接 |
| Claim | 可验证命题候选 | 自动成立的事实 |
| Fact | 指定条件下有充分依据的陈述 | 永远不变的内容 |
| Valid time | 现实中适用时间 | 系统得知时间 |
| Recorded time | 系统登记时间 | 生效时间 |
| Scope | 租户、项目或用户归属 | 最终访问许可 |
| Checkpoint | 执行位置与恢复数据 | 经验摘要 |
| DerivedArtifact | 关联输入版本的派生表示 | 独立权威事实 |
| Consolidation | 整理并形成紧凑记忆 | 丢掉全部依据 |
| Forgetting | 降权、失效或删除，需明示 | 自动履行删除 |
| RAG | 外部信息辅助生成机制族 | 单一向量库 |
| LLM Wiki | 模型辅助主题视图 | 某特定产品 |
