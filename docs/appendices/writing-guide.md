# 写作与证据规范

每篇包含问题、机制、完整条件、例子、局限与引用入口，解释为什么和如何，避免只列产品。

引用结论限定论文和场景；架构用“建议”“参考”；实测附配置与日志。未经运行不得写已实现或虚构百分比。Atlas 情节均为合成。

来源、证据、信息对象、检查点和派生物保持一致定义。有效时间与记录时间分开，默认区间左闭右开，未知结束为 null。删除与失效不同。

Mermaid 邻近文字解释箭头。语法检查不等于视觉布局审查。模型调整先改术语与契约，再修受影响章节。

引用靠近所支持陈述，文献索引说明核验范围和日期。仅核验摘要不宣称完整复现，不复制第三方整图。

首稿表示有完整可读论述，不代表经过同行审稿。待研究方向进路线图，不用空段落冒充覆盖。
