# 评测执行规程

## 研究问题与运行边界

检验知识与记忆联合机制是否提高任务质量，同时控制时态错误、权限泄露、纠错残留与成本。本仓库尚无完整被测系统，以下是后续实现的实验规程；离线评分脚本只评集合召回与禁止项残留，不评生成质量或真实授权实现。

## 准备数据

1. 从 Atlas 时间线构造文档版本、偏好对话和行动轨迹，保留原始来源。每题标记查询主体、时点、相关证据、禁止项、可回答性和独立标准答案。
2. 以用户/项目与完整事件链分组拆分 train/dev/test，避免同一链或改写问题跨集合泄露。小型附带 fixture 仅展示 test 格式，不可用它调参后再报告泛化。
3. 每条真值由两名标注者独立判断，分歧复核；保存条件、来源与判定理由。扩展集应覆盖迟到、冲突、否定、例外、撤权、删除和无答案。
4. 记录数据哈希、许可、版本、生成方式和拆分脚本版本；合成与真实数据分开报告。用合成多租户数据注入越权请求，不使用真实秘密。

## 冻结配置

复制 run-config.json 为实际运行配置，填模型精确版本、提示哈希、语料哈希、tokenizer、检索和重排模型、时间戳与价格日期。缺字段则不启动正式比较。固定随机种子，至少重复配置中规定次数；外部服务非确定性需在报告中注明。

## 执行各条件

无外部信息只见问题；Long Context 见授权历史并按预定策略截取；RAG 只检索组织知识；Memory 只访问个人历史；Wiki 与 Graph 分开运行；Hybrid 组合访问。所有条件同一原始可见语料、同一模型、同一输出预算。另报告资源不匹配的最佳质量实验，不与预算匹配结果混淆。

对每题保存 query_id、条件、运行号、输入证据 ID/版本、最终上下文、答案、拒答状态、延迟分段、Token、检索分数及错误码。日志脱敏并限制访问；不把隐藏思考过程作为必要产物。

## 离线评分演示

```sh
node scripts/score.mjs examples/evaluation/gold.json examples/evaluation/sample-predictions.json
```

sample-predictions 是手写金标准回放，不是模型预测。脚本按题检查 ID 一致、去重后的 Recall@K 和禁止项残留；无相关证据题不进入 recall 平均，单独统计。正式预测必须由实现的系统产生，不能复用演示文件报告效果。

生成评测需要另外标注：答案事实正确、是否被实际上下文支持、当前/历史时点是否正确、误拒与应拒、证据不足处理。自动裁判需人工抽样校准，并对模型身份和实验条件盲化。

## 状态与故障实验

| 场景 | 注入点 | 判据 |
| --- | --- | --- |
| 写入重复 | 同事件投递两次 | 只有一个有效版本 |
| 乱序旧事件 | v2 后到 v1 | 当前规则不回退 |
| 删除后旧任务 | tombstone 后重放索引 | 不能重新可见 |
| 撤权缓存 | 缓存命中时改 ACL | 最终输出无旧内容 |
| 共享摘要 | 删除一个输入依赖 | 剥离或失效重建，不保留泄露 |
| 部分提交 | 主记录提交、索引失败 | 任务可重试且无重复主记录 |
| 恢复副作用 | 远端成功、本地确认前中断 | 先核对远端，无重复动作 |
| 冲突 | 同范围互斥规则 | 标记争议，不静默覆盖 |

分别记录在线阻断与最终清理延迟，备份恢复后再次核验删除账本。消融关闭重排、时间权重或压缩，权限防护不在真实共享数据中关闭。

## 汇总与报告

按题型和作用域报告召回、事实正确率、忠实度、时态错误、残留、误拒、p50/p95/p99、构建与维护摊销成本。按同题配对比较条件差异，bootstrap 置信区间需按独立事件链采样；小样本不宣称显著性或生产效果。人工列出典型失败和回归。

[结果模板](../../reports/experiment-template.md)不预填成绩。任何正式结论都要附 commit、数据配置哈希、原始预测与复核记录。
