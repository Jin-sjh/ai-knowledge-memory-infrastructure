# 2.1 信息的语义分类

[全书首页](../../README.md) · [本章导读](README.md)

> 概念说明与参考设计，非已实现系统报告。核验日期：2026-11-13。

## 要解决的问题

信息应按什么维度分类？

语义类型回答内容在表达什么，不回答谁可访问或用哪种数据库。事件可包含实体、关系和事实；先拆出可验证断言，再保留事件级关联。

### 2.1.1 Fact：事实

“本次有两人完成审批”描述已经发生的事件，“发布必须两人审批”规定允许行动的条件。两句话都有“两人”，却不能互相证明：日志中的人数不能替代规范，规范也不能证明本次已完成审批。

保存事实时明确对象、时间、计数口径和依据。例如两个审批条目可能来自同一人；只有核对身份，才能形成“两名不同审批者”的结论。

### 2.1.2 Concept：概念

概念用于固定讨论口径。例如审批者是拥有资格并作出有效决定的人，不一定等于提交人、执行人或页面中的任意操作人。若定义不清，后续人数统计与角色限制会使用不同含义。

定义应带领域和版本。两个项目对“负责人”理解不同，应分别保存，而不是看到同名就合并。

### 2.1.3 Entity：实体

实体是需要稳定识别的对象，例如用户 u1、Atlas 项目或某次发布。名称只是文本提及，同名项目、简称和改名都可能造成误关联。

用稳定 ID 关联对象，同时保留原文名称供解释。无法确定“Atlas”指哪个项目时，保留待确认候选；不能把一方的规则写入另一项目再等待后续修正。

### 2.1.4 Relation：关系

关系需要两端、方向及角色。“u1 提交 r1”和“u1 审批 r1”涉及相同对象，却对审批资格产生不同影响。无类型连线无法支持“提交者不能审批”的判断。

关系还可带时间和出处，例如某人只在本周担任负责人。当前授权应检查关系有效性，不能沿用历史角色。

### 2.1.5 Rule：规则

规则描述特定前提下的要求、许可或禁止。“普通生产发布需两名不同审批者，提交人不能审批”同时约束环境、类型、人数和角色。只抽取人数会扩大或缩小许可范围。

保留完整可读原文，再按业务需要增加可计算条件；未经验证的自然语言候选可辅助解释，不应直接驱动执行。

分类时同时保存原始表达与规范化断言。原文“这次可以先别走双人审批”至少包含说话者、一次性范围和可能的授权问题，不能直接提成“发布不需要双人审批”。规范化记录可写为主体 atlas、行为 ordinary_release、条件 current_request、陈述 candidate_exception，并标记尚未验证授权。

这里区分语义与治理尤其重要：一条 Preference 可以是公开测试数据，也可以是私有个人偏好；一条 Rule 可以是候选而非有效规则。语义类型无法代替访问和验证状态。

### 2.1.6 Event：事件

事件记录某时点发生的事，例如偏好表达、审批完成或请求超时。要区分“请求已发出”和“远端已完成”：前者不能证明副作用已发生，后者还可能缺少本地确认。

原始事件保留主体、时间和结果，摘要与当前状态可以另外生成。恢复任务时需要准确事件边界，不能只有“处理过了”。

### 2.1.7 Preference：偏好

偏好表达主体在某范围内希望怎样响应，例如“讨论 Atlas 时先给结论”。主体、项目和适用条件都是语义的一部分，不能提炼成无条件的“用户喜欢简短”。

当前任务要求可以覆盖默认，但未必改变长期档案。先识别一次性请求与长期更正，再决定保存方式；读取时还要核对当前任务的范围。

参考设计可用 subject、attribute、value、valid_from、scope 约束当前视图，并关联原始表达。Mem0 追加变化文本可作为事件线索，但不能把提取文本直接当成完整的时态档案。对明确更正，应用需要另行规定替代关系与访问策略。[固定版本源码](https://github.com/mem0ai/mem0/blob/f1791daa86d469249c9b002f62644d58a1eb96a0/mem0/memory/main.py#L918-L1098)。

### 2.1.8 Experience：经验

经验连接情景、行动与结果。例如“升级后启动失败，回退配置后恢复”提供排查线索，但同时变化的环境因素也可能影响结果，不能直接认定唯一因果。

保存版本、输入和操作顺序，使以后能够判断可比性。经过复现或独立验证，经验才适合提升为稳定方法。

### 2.1.9 Procedure：程序性知识

程序性知识应说明环境、步骤、成功判据和失败处理。“运行检查后发布”还没有告诉读者在哪里检查、执行什么、哪种结果算通过。

保存的程序可供人阅读，也可由工具执行，但保存方法不等于授权动作。Agent 使用前仍需核对当前项目、依赖版本和操作权限。
